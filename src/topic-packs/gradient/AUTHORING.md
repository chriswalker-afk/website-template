# Gradient — IGCSE Foundation

This topic covers gradient of straight-line graphs only. It has been authored as the first full reuse test of the website template.

Curriculum core: rise ÷ run on a squared grid; positive, negative, flat and vertical line distinctions; gradient as the coefficient m in y = mx + c; consistent change in tables and contexts. Two-point coordinate calculations are labelled extension work in the highest level.

Ready for publication. Run `npm run audit:topic -- --topic gradient --strict`, then `npm run build:site -- --topic gradient`. See [Pass 5 summary](../../../docs/PASS_5_GRADIENT.md) for full coverage and testing.
